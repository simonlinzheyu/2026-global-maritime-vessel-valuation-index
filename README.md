# September 2026 Global Dry Bulk Second-Hand S&P Valuation Index

Open institutional maritime transaction dataset compiled by **ShipsTrading Maritime Intelligence** (`shipstrading.com`).

## Dataset Overview
- **Coverage:** 58 verified global dry bulk sale and purchase (S&P) transactions recorded in September 2026 (VLOC, Capesize, Post-Panamax, Kamsarmax, Panamax, Ultramax, Supramax, MPP, OHBC, and Handysize).
- **Fields:** `Segment`, `Vessel_Name`, `Built_Year`, `DWT`, `Shipyard`, `Price_USD_Millions`, `Buyer_Profile`, `Remarks`, `Source_URL`.
- **Full Market Analysis & Live Fleet Directory:** [September 2026 Dry Bulk S&P Market Report](https://shipstrading.com/september-2026-dry-bulk-sp-sales-valuation-report/)
- **Canonical DOI:** [10.5281/zenodo.24239681](https://doi.org/10.5281/zenodo.24239681)
